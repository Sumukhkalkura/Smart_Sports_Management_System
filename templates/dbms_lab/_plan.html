How to read this plan
  • The plan is a tree; the most indented nodes run first and feed their parents.
  • Seq Scan reads every page of the table without using an index. Index Scan walks an index to find matching rows; Index Only Scan answers from the index alone; Bitmap scans collect matching row locations first, then visit the table.
  • cost=startup..total is the planner's estimate in arbitrary units; rows is the estimated row count. The planner chooses the cheapest plan based on table statistics (ANALYZE).
  • With ANALYZE, actual time=… (ms), rows and loops are real measurements; "Execution Time" is the measured total.
  • An index does not make every query faster: for small tables or queries returning a large fraction of rows, a sequential scan is cheaper.
